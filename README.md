# Ofertas en seguridad, redes y tecnología

Página pública de precios. Se actualiza automáticamente cada día.

## Catálogo completo (catalogo.html)
Cada día (6:17 a.m.) una acción de GitHub descarga los productos con existencia
desde la API de distribuidores y publica `catalogo/` junto con el sitio.
Requiere estos secretos en Settings → Secrets and variables → Actions:
`SYSCOM_CLIENT_ID` y `SYSCOM_CLIENT_SECRET` (o `SYSCOM_TOKEN`).
Margen opcional en Variables: `MARGEN` (por defecto 0.15).
